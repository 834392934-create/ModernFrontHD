# 公开外观参照与精度边界

## 设计目标

《坦克世界》作为细节层次、材质和装备检视的表现参考，不搬运其模型、贴图、代码或游戏数据。
官方图形技术介绍：[Core 画质与优化](https://worldoftanks.eu/en/news/general-news/update-1-0-graphics-engine-technologies/)。

## 独立坦克外观研究

- ZTZ-99A：低车体、六负重轮、楔形炮塔正面、分段侧裙、外部观瞄；[中国国防部公开训练照片](https://eng.mod.gov.cn/xb/Home/Focus/16300466.html)。
- M1A2：七负重轮、较大的焊接炮塔和尾舱、炮塔后框架、顶部武器站；[美国陆军 SEPv3 项目](https://cpeground.army.mil/Combat-Platforms/Project-Manager-Abrams/)，[SEPv3 公开生产照片](https://www.armytimes.com/news/your-army/2017/10/25/army-receives-upgraded-abrams-tank-and-more-improvements-are-on-the-way/)。
- T-90M / T-90S：较低圆弧炮塔基形与外装模块、六负重轮；[公开出口型资料](https://roe.ru/pdfs/pdf_4437.pdf)。M 与 S 的具体差异未完成逐批次摄影测量，不能称精确复刻。
- K2：低平焊接炮塔、六负重轮、侧裙与尾舱；[现代 Rotem 官方产品页](https://www.hyundai-rotem.co.kr/en/business/defense/details.do?productCt03=defense0101)，[官方侧向照片](https://www.hyundai-rotem.co.kr/common_en/images/img-defense-k2.png)。
- 帝国装甲：同人科幻视觉，独立加强炮塔与装甲外形，不宣称对应现实坦克。

每个外观研究包含独立实体的轮胎、轮辋、轮毂、可见螺栓、履带块、履带齿、侧裙与紧固件、首上倾斜装甲、舱盖与把手、炮管外观热护套、观瞄玻璃、顶部武器站、外置发烟管、天线、发动机格栅、灯具和拖曳耳。

注意：这些是依据照片做的原创可辨识模型，未进行摄影测量、逐面尺寸核对或装配扫描。所有模型尺寸都是视觉比例。它们不等于军事工程模型，不应宣称达到《坦克世界》的商业资产质量，也不能用于制造真实部件。

## 空天模型

无尾概念机使用用途推演的折线机翼、内置舱门、进排气轮廓、座舱和传感器窗。F-47 公开信息仅支持研发项目身份，不足以证明本模型外形为真实最终构型。通用概念机图集不会被称为 F-35 或 J-20 的精确外形。

轨道侦察平台包含服务舱、太阳翼、通信天线、载荷窗口与散热面；不推断 X-37B 内部载荷。轨道战舰与光束载荷为明确标注的架空作战模型。

海军、航空、步战车和炮兵本版仍有通用类型模型。逐型号外形复刻尚未完成，不能因显示真实型号名称而视为已完成。
