# 导航包围体独立监督

2026-10-18，CPU 检查，不运行 GPU，不提交 Git。测试：`tests/navigation-footprints.test.cjs`。

现有实现以程序模型测量的旋转矩形检查地形，与阻塞格使用四轴分离判定，避免只检查中心或稀疏采样点漏过内部障碍。实体间停位保留外接圆，战斗命中半径不随视觉包围体放大。分层使用世界高度加模型上下界。

已验证：四地图 × 五出生舰槽完整包围体合法；各推进 20 秒、每步检查舰体没有跨岸，全部离开初始位置至少 40 u。跨批次停位避让先前队列最终目的地；排队攻击目标与 attack 标志及存档恢复一致；不同高度层不互占投影停位；连续两次生产位置避让前一艘完整船体；无合法生产水域返回 null。注册表 462 个模型包围体具有有限尺寸，半径不超过 160 u。

发现并在授权范围修复：第一人称原 directPositionFree 仅用战斗半径和八点采样。中国驱逐舰中心 (1400,1500)、岸线 x=1440 时，26 u 战斗圆在水中但舰艏上岸。函数增加统一完整包围体地形检查，保留原飞行高度、结构、矿区、树木保护。驾驶、深度飞行、跳跃三组 47/47 测试通过，输入稳定 11/11 通过。

已反馈主线程、由对应运行时负责人闭合：

- 静止旋转：同一舰船 angle=π/2 时合法，手动 yaw=0 后舰艏越岸；角度赋值在 position guard 前。已获授权修复 stepDirectControl：非飞机转向按不超过 0.08 rad 分段检查旋转包围体，碰岸停在最后合法角度，地面平移采用已接受的机身角度。额外验证 180° 转向两端合法但中途碰岸，以及潜艇连续转向；飞机原角速度与气动分支保留。导航 move 的候选角度问题已由拥堵 agent 修复。
- 存档半径：Game.load 原接受 e.r=1e9，足以污染停位、生产和路径膨胀；主线程已由注册单位定义恢复 r，独立回归通过。
- 无可航地形：12 艘航母、全海图阻塞、同批命令原产生 8,691,820 次 terrain 查询，本机一次 CPU 实测约 1.51 秒；destination 失败回退当前位置仍有 1 艘被标为接受。主线程现已增加共享工作预算与明确失败返回，独立回归通过。测试用查询次数而非墙钟限额，要求整批低于 500,000 次且全部拒绝。该测量为异常地图/不兼容位置边界，不代表正常战斗性能。
- command 在连通性和 queue-full 拒绝前先写 reserved/plan，会暂时预留未被接受的新停位；已给主线程作为低优先级审查意见。

这些结论不代替真实 GPU、真实导入资产包围体、长期拥堵性能或发布 EXE 验证。以主线程最终回归结果为闭合依据。

追加转向及主线程修复后的独立回归：导航 12 项，加驾驶、深度飞行、跳跃、输入稳定，共 70/70 项通过。异常无水域案例复测实际 16,384 次 terrain 查询、约 11.48 ms，12 艘全部拒绝；此为单次 CPU 观测，不作为通用帧率承诺。
