# 防御设施范围与作战规则审查

日期：2026-10-16。审查基线：2.1 / a3f6226。此文档记录独立只读审查；主 agent 实现后另记录截图与规则复核，不能把建议当成已完成。

## 第一轮：实现前发现

### P1：模拟与提示必须使用同一份范围规则

建议在 `Game` 内增加公共 `rangeProfile(entity)` / `effectiveRange(entity)` 和 `sightRadius(entity)`。战斗、选中提示、悬停提示、建造预览均消费同一接口，不在渲染器重复计算“雷达 ×1.15”。接口至少返回基础/有效攻击半径、最小射程、拦截半径、支援半径、可攻击目标域、运行状态与原因。

当前 `sim.js` 对有伤害的建筑，在己方活雷达 450 游戏单位内增加 15% 射程，雷达 EMP 会取消增益，但没有电力检查。基础炮塔在缺电时仍能开火，因此会错误地受益于失电雷达。`teamEntities` 已过滤死亡建筑，不需要重复修复死亡雷达条件。

### P1：区分攻击、拦截、侦察、支援圈

| 设施 | 基础范围（游戏单位） | 规则/提示 |
| --- | ---: | --- |
| 防御炮塔 | 攻击 275 | 地面、海面、空中；不攻击太空；缺电仍工作，EMP 停机 |
| 加固火力堡垒 | 攻击 255 | 地面、海面；需供电 |
| 防空导弹阵地 | 攻击 510 | 仅空中，不包含太空 |
| 近防炮 | 攻击 330；拦截 330 | 攻击地海空；雷达后攻击 379.5，火箭拦截仍 330；不得把核打击也写成可拦截 |
| 定向能炮塔 | 攻击 440 | 地海空；不攻击太空 |
| 联合警戒雷达 | 侦察 750；联动 450 | 无攻击；联动内有伤害建筑射程 +15% |
| 维修站 | 维修 210 | 仅己方移动单位，不维修建筑 |
| 护盾 | 保护 240 | 对己方单位及建筑减伤 45%，多个护盾取最大值不叠加 |
| 电磁塔 | 压制 290 | 对敌方移动单位持续禁用，不禁用建筑 |

以上是游戏数值，不是实物性能，不应显示“米”或宣称真实命中范围。火炮/火箭车的最小射程 100/125 应用内圈表示，并与最终扩充兵种的数据一致。

### P1：雷达视野不是固定 750

玩家视野使用阵营乘数：美国雷达 862.5，帝国雷达 937.5。现有雷达 EMP 后仍维持远程视野，AI 的 `unitsInSight` 则把所有建筑固定为 330，忽略雷达和阵营乘数。这些规则应统一，否则同一种雷达的可见圈与实际行为会依阵营/玩家 AI 身份出现差异。

建议 `sightRadius` 对正常雷达使用 `750 × faction.vision`，缺电/EMP 雷达回退 `330 × faction.vision`，玩家和 AI 一致。全图视野玩家增益属于全局效果，独立显示，不能把单个雷达圈无限扩大。

### P1：提示状态与预览

- 选中与悬停显示相应圈；建造前显示拟放置位置的范围及雷达增益。
- 缺电/EMP 使用灰色虚线并明确“停机/标称范围”，不要画有效火力色却无法攻击。
- 建造预览须考虑该设施建成后的耗电。当前有余量 10、拟建 SAM 耗电 25 时，不能把预览画成正常启动。
- 基础 `turret` 没有 `defense:true`，按此字段显示“所有防御范围”会漏掉最常用炮塔。
- 隐藏敌方设施不能泄露；敌方仅在已可见时显示范围。
- 太空/空中半径是地图水平距离：可在地面投影显示，但标注目标域，避免误以为高度增加/缩短射程。

### P2：可读性与性能

- 默认只显示选中/悬停/放置范围；全防御范围作为可切换选项，防止大量彩圈淹没战场。
- 攻击圈、盲区圈、支援圈需要线型与文字共同区分，不能只依赖颜色。
- 单选信息至少含：攻击目标域、有效射程、基础射程、雷达增益、停机原因。
- 3D 与兼容 2D 渲染器均实现；不要只更新当前显卡能看到的路径。
- 同一帧缓存己方雷达/电力等；多选几十单位时不反复遍历所有实体。

## 建议的行为验证

1. 无雷达炮塔不能命中 300 距离的静止敌人；450 联动范围内有正常雷达后可以命中；移出 450、EMP 雷达或缺电时恢复 275。
2. 缺电普通炮塔仍开火；缺电 SAM/激光停机；电力恢复后恢复攻击。UI 与此一致。
3. SAM 对飞机开火，对地面、舰船、太空不攻击。CIWS 拦截进入 330 的火箭，不能因为攻击增益扩大拦截范围。
4. 火炮盲区内不能开火，内圈外能够开火；目标连续移动越界时同步改变。
5. 雷达侦察圈在美国/中国/帝国，正常/EMP/缺电状态下与 `sightRadius` 结果一致；AI 与玩家用相同函数。
6. 维修/护盾/电磁圈内外各放一组对象，确认支援域、范围边界、停机状态。
7. UI 截图至少覆盖：炮塔 + 雷达双圈、SAM 空中限定、CIWS 双半径、缺电停机、建造预览、最小射程内圈、2D 兼容路径。
8. 开启所有防御范围的战斗短测应报告实体数、画面尺寸和渲染时间；不要把截图通过等同于性能稳定。
