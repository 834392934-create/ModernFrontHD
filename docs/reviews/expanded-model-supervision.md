# 扩展兵种模型独立监督

日期：2026-10-16。审查者：expanded_model_supervisor agent。范围：新增陆海空天通用作战角色；不修改源码，不替代真实装备逐型复核。

## 验收标准

1. **角色轮廓**：每个新增兵种至少拥有一个在检视器中明确可见的任务构型，并在游戏视角/生产缩略图中保持主要区别。仅改名、换色或等比例缩放不能通过。允许合理共用底盘/舰体，但必须有设备和布局差异。
2. **构型语义**：无武装侦察/维修单位不得保留显眼的主炮或导弹架；维修设备、传感器、雷达、炮管、发射器应与实际实现的职责一致。不能用没有游戏机制的运输/布雷/电子战部件暗示未实现能力。
3. **空间一致性**：车辆轮组接地、舰艇水线合理、飞行器与太空单位按域放置；模型前向统一，炮塔转轴与旋翼中心正确；旋翼/雷达能实际转动，枪口效果不能从车底或建筑地基出现。
4. **同源交付**：主战场、检视器、头像必须调用同一注册模型源；所有新增种类 × 6 阵营能够创建，边界盒有限，无空网格，且生产入口和画册入口可达。
5. **来源诚实**：新增通用角色不沿用 T-90M、AH-64 Longbow、Burke 等导入型号的真实性或许可字段冒充新型号。若复用第三方实际网格，必须保留署名、许可、来源及修改说明；原创结构则标记游戏设计。
6. **能力匹配**：太空域优先于 air 布尔标记；无武装角色永不发射；对空/反轨/攻城/维修各有正确目标域。角色辨识评审不能以面数或自动化测试替代。

## 复核方法

- 首轮：阅读新增模型模块，检查注册覆盖、元数据和动画节点；实际查看按域排列的全角色接触表。
- 第二轮：针对首轮 P1 问题查看更改后的同角度图，并抽查侧视/俯视和生产头像。
- 输出限定为“原创游戏角色辨识通过/有条件通过/待修正”，不授予“真实精确还原”结论。
