研究日期：2026-10-16。研究 agent：space_reference。仅提交设计参考，视觉通过由独立监督 agent 判断。

本轮用户明确要求重新设计太空武器并允许参考影视，作为此前轨道概念冻结规则的局部例外。影视舰船、以下原创武器性能都不是现实装备资料。其他未知实物/六代机不因此解除冻结。研究图片仅保存在 `.tmp/references/space`，不打包、不作模型贴图、不提取影视/商业游戏资产。

## 四种原创单元的可执行设计指标

比例是美术设计目标，非现实武器尺寸。所有发光攻击均为游戏可读性效果。

| 单元 | 主轮廓（不依赖颜色） | 建模重点 | 材质/色彩 | 动态与攻击表达 |
|---|---|---|---|---|
| 无武装侦察卫星 | 小箱舱 + 两侧大薄翼，展开总宽约主体宽 3–4 倍 | 3 段电池翼、可见铰链；短粗光学筒、碟形天线；小姿控喷口，无炮台 | 银白/金色隔热包覆，深蓝电池格；扫描用浅青 | 太阳翼慢速调整，光学头独立扫动；只用扫描圈，绝无炮弹/伤害光束 |
| 轨道截击舰 | 长宽比约 3.5–4.5 的窄舰体，尾端双喷口，前端双叉短炮架 | 细长中央脊梁、分段装甲、两侧收拢散热片、前向发射座、侧面小姿控喷口 | 冷灰装甲、白散热板，少量青灯；尾部蓝白 | 快转向/短尾焰；前端小口径脉冲或导弹轨迹，定位海面/空中/太空机动目标，射击不能从腹部重平台节点冒出 |
| 重型对地平台 | 宽六/八边框架，长宽比接近 1，中心大孔洞，下吊中心节点 | 外圈厚节点、薄桁架交叉杆、四/六散热翼、中心发射器与外圈用细梁连接；底视仍可辨发射器 | 米白/石墨灰；散热片白色，蓄能件琥珀 | 低速，内圈慢转；预热由边缘向中心，随后单束向地面；海陆空基地全域能力如保留，也须不同于截击舰的攻击表现 |
| 帝国重装轨道舰 | 厚长船体 + 三座纵向高塔 + 侧舷外凸炮舱，不能像扁环平台 | 钝重船艏、装甲肋、拱形支撑、分层舰脊、高塔、侧舷成组炮口、三/四尾喷口 | 暗红/铁黑主体，旧金边、少量青色/紫色装置；不要全身高亮 | 较慢且稳，侧舷分组闪光与前向重束分开；护盾只在受击局部闪现，避免常亮球遮模型 |

地面 **asat** 单独处理：重型轮式/履带底盘、有接地车轮、顶部竖直发射筒/仰角跟踪头、折叠支腿和电源舱；重心明确在地面。不能复用轨道卫星翼板，也不能浮空。其概念外形可来自通用雷达/防空发射车结构，不能假称某型真实反卫星装备的准确复刻。

## 阵营差异与命名

- 四种“类别”的轮廓区别优先于阵营换色。五个现实阵营可在同一原创类别下改变翼板数、机鼻/传感器形状、喷口布置和装甲节奏；不要借阵营标签假称该国已公开对应武器。
- USA 旧名 `X-37B` 与双翼箱形卫星不对应，CHN 旧名“可重复使用试验航天器”也不对应；若采用新卫星外形，改为原创侦察卫星名。帝国原创大舰不继续借“月级”名称暗示精确复刻。
- 每个新模型 metadata 标明 `原创科幻概念` 与参考页面；引用影视意向不等于取得影视素材商用许可。

## 给监督 agent 的验收要点

1. 顶/侧/前/后/透视五视图。侦察薄翼、截击窄长、平台镂空、帝国厚船高塔四个形态在 96 px 缩略图仍可辨。
2. 临时隐藏阵营色和发光，仍能准确分辨类别；近距离不能出现悬空桁架/面板或明显穿插炮口。
3. 枪炮、扫描、推进的位置匹配相应可见装置；侦察实际零伤害，asat 保持地面，平台仍符合玩家全域攻击设置。
4. 夜景保留结构信息，不能只剩几何霓虹；主战场、检视器、缩略图使用同一源。
5. 影视参考不是“真实还原”验收；通过应写“原创设计区分度/结构可信度通过”，不能写“现实轨道武器复刻通过”。
