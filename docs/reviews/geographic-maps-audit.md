# 真实地理大地图实现与验收记录

日期：2026-10-25。基线：`9fa9c67` / 3.14.0。此记录针对地图与尺寸切片；原生窗口、最终版本包及 GPU 验收由主控另行记录。

## 结果与范围

新增 `english_channel`（英吉利海峡）、`gibraltar`（直布罗陀海峡）、`taiwan_strait`（台湾海峡），各为 **12288×8448 游戏单位、48 单位地形格、256×176 格**。面积为旧图的 4 倍；没有把游戏单位冒充地理米。

四张旧图仍为 6144×4224、128×88 格。旧 `tiles`、陆海阻挡、出生点、据点、港口、舰艇出生点的 SHA-256 与基线逐图一致；全局 `WarData.W/H` 没有随对局修改。

所有新图保留 5 个完整出生基地、5 座矿山、5 个港口、5 个舰艇位置、6 个经济据点。初始实体数与旧图相同；树木仍最多 170 棵。港口与内陆基地分开挑选，不修改海岸来容纳建筑。

## 地理来源与可复现导入

- 来源：Natural Earth 1:50m land，公共领域；[使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。
- 原仓库：`nvkelso/natural-earth-vector`，固定提交 `ca96624a56bd078437bca8184e78163e5039ad19`，文件 `geojson/ne_50m_land.geojson`。
- 原始输入 SHA-256：`e874b27a51d146452be360cafb3cc50c86001074a67d534113e6534682f9826b`。
- `tools/build-geographic-maps.cjs` 检查输入哈希，将经纬度多边形裁剪、量化，按格心生成离线陆地掩码。运行：`node tools/build-geographic-maps.cjs <已下载的 ne_50m_land.geojson>`。
- 成品为约 23 KB 的 `src/map-geography.js`，包含裁剪后的多边形、RLE 陆地掩码和来源；许可与投影清单位于 `assets/maps/geography-source.json`。游戏无需请求网络。

采用中心纬度等距圆柱近似，北向上，轻微扩展经度边界以保持场景长宽比：

|---|---|---:|

地理资料仅决定陆海轮廓。基地、港口、矿山、据点是虚构游戏位置；地图进行了距离压缩。没有引入地形高程、城市街道或海底测深资料，不表示真实军事设施位置、可航水深或作战距离。50m 是 Natural Earth 数据比例尺类别（1:50,000,000），不是 50 米空间精度。

## 实现边界与主路径

| 主路径 | 行为与检查重点 |
|---|---|
| `src/map-dimensions.js` | `forMap(map/id/game)` 返回 width/height/tileSize/cols/rows 及 W/H/T/COLS/ROWS 同义字段；只读独立尺寸，检查整数网格和缓存后篡改。 |
| `src/maps-large.js` | 旧算法保持；新图从离线陆海掩码选完整陆地基地，按保守舰体空间选择同一海域港口，不改海岸格。 |
| `src/sim.js` | 实例内出生、移动、建造、雾、路径、舰队接近点、保存加载均读当前地图；A* 保留斜角阻挡规则。 |
| `src/navigation-footprints.js` / `crowd-navigation.js` | 精确地形碰撞与动态路径掩码采用当前尺寸；传给 A* 的派生掩码带回地图尺寸，避免仅 `{blocked}` 回退旧边界。 |
| 航空、航母、乘员、运输、损伤、齐射模块 | 跨旧边界飞行、返回、离舱、坠落与齐射落点按本局地图检查；`carrier.validate(e,map)` 接受显式地图。 |
| `src/battle3d.js` / `render.js` | 摄像机、地形和小地图按本图尺度；雾尺寸为 shader uniform，换图重建尺寸相关缓存。两条渲染路径地图纹理均限制 2048×1408；备用 2D 画布不按全世界像素分配。 |
| `src/app.js` | 地图卡片、切图镜头、小地图点击定位使用当前图尺寸。 |
| `src/destructible-trees.js` / `underwater.js` / `altitude-scene.js` | 生成与景观尺寸跟随本图，保持装饰数量预算；切图清理旧轨道背景资源。 |
| `tests/geographic-maps.test.cjs` | 真实 Game、完整包络、经济回路、保存、CPU 渲染、来源和地图边界回归。 |

保留 `mapScaleVersion:2`。新保存写入 `mapGeometry`（schema 1）并验证尺寸与地图 ID；旧地图无此字段的存档仍可载入。新地理图不得伪装成旧坐标缩放存档。树木键使用本图尺寸，旧地图键不变。

## CPU 验证与限制

新地图 20 项专项验证包括：

1. 大图 A* 到达 x=11976、y=7992，同时旧图仍可正常寻路。
2. 四旧图 SHA-256 完全一致；三新图每一格陆海状态均与离线资料一致。
3. 15 个初始基地的全部建筑与单位包络、矿区及本地据点连通。
4. 全部港口同海域；6 个阵营航母在 5 个舰艇位置、8 个朝向均完整处于水域。
5. 每图真实模拟 120 秒，15 队矿车均完成至少 500 资源的一次满载回收；每 tick 检查完整车辆包络没有跨岸。
6. 每个基地可在既有陆地合法建机场及完整独立跑道，包含进近边界检查。
7. 大图与旧图同进程并存，远侧单位、迷雾、派生寻路掩码、坐标与存档正确；错配尺寸存档拒绝。
8. CPU 备用渲染纹理上限、小地图坐标、镜头边界和 3D 雾 old→large→old 缓存切换。

旧地图/树木/导航/基础模拟套件首次为 57/59；两项失败是旧测试把所有非群岛图当连续大陆、以及海路夹具丢失地图尺寸。对应断言已按真实陆块分组保留“同岸通行、跨岸不得穿海”的约束，并使用实际尺寸；两项定向复跑通过。没有削弱碰撞、航道或到达标准。
