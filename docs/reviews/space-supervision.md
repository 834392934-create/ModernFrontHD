# 太空单位独立监督记录

审查日期：2026-10-16。审查者：space_supervisor agent；制作由主线程负责，本审查者不修改游戏源码。

## 授权边界

用户本轮明确要求重新设计太空武器、区分单位，并指定一名参考研究 agent 与一名监督 agent。此次允许四类太空相关原创概念细化：无武装侦察平台、轨道截击艇、重型全域打击舰、陆基反轨平台。用户随后授权全部17类建筑细化，包括激光、护盾、干扰建筑。该例外不代表其余未知武器的实物验收已通过；六代机及其他未知车辆、舰艇、航空器仍冻结。

影视画面只用于构图、轮廓、功能分区和材料语言启发。原创虚构装备不宣称真实现役，也不将影视图片作为贴图或未经许可复制影视模型。

## 制作前查到的问题

- `models3d.js` 中旧 satellite 与 orbital 共用盒形本体和双太阳翼，重型武装仅多一根长管，无法从角色读懂外形。
- asat 进入通用卡车模型分支，不能传达地对轨发射用途。
- 图集只展示中国旧轨道占位，无法比较阵营；旧模型描述仍称暂缓。
- 所有轨道射击共用普通曳光，陆基反轨发射与截击艇武器尚无视觉区别。
- 单位类型、AI选择、测试路径名单、清单分类与生产缩略图存在硬编码，同步检查是交付门槛。

## 验收标准

| 编号 | 检查 | 通过依据 |
|---|---|---|
| V1 | 四型角色轮廓 | 侦察平台以传感器/太阳阵列为主，无大炮；截击艇紧凑、推进系统明确；重舰明显更重，有轴向武器/散热结构；陆基平台有地面底盘/发射结构。实际查看透视与俯视截图，不凭部件数通过。 |
| V2 | 六阵营区别 | 至少在主轮廓、动力/散热布置、天线/武器构型上体现阵营差异，不能只有换色。帝国重舰的体量、装甲/舰桥语言应明显不同。 |
| V3 | 模型运行 | 战场、图集、头像同源；炮口方向、朝向、地面接触及轨道高度可理解，窄屏与缩略图仍能识别角色。 |
| G1 | 攻击职责 | satellite 不伤害敌人；interceptor 只攻击航空/轨道；orbital 可攻击轨道/航空/海军/地面/建筑；asat 仅攻击轨道。以各目标层实际伤害测试验证。 |
| G2 | 权限 | 关闭AI太空武器时同时阻止重舰、截击艇训练，退还对应队列，清除已有AI禁用平台及相关延迟攻击；无武装卫星、陆基反轨保留。在advanced与playerOnlyTech组合下符合对应权限。 |
| G3 | 生命周期 | 新kind能训练、生产、移动、编队、攻击、存档恢复；AI获准后可选择生产；旧存档仍可载入。 |
| G4 | 攻击效果 | 地面反轨发射自地面，截击火力自较低轨道层，重舰全域束流或弹道从舰体发出；终点对应目标高度，颜色/形态可区分。 |
| D1 | 证据与标签 | 原创概念与实物外观复核明确分开，参考页面与影视启发记录可追溯，任何图集/名称不把原创平台冒称真实已部署武器。 |
| D2 | 交付 | 单元测试、所有模型渲染、更新后头像、实际桌面离线版本运行；性能记录包含硬件与场景，不用软件测试代替视觉通过。 |

参考研究 agent 已查看制作方及 NASA/ESA 图片，记录在 `space-reference-review.md`。可读性复核加看96px缩略图：在弱化阵营色和发光后仍应辨别角色。白色散热板与蓝色/棕金色太阳电池翼须有材质区别。参考文档的比例数字为美术建议，不作为真实武器尺寸或要求所有阵营统一外形的硬门槛。

## 新增建筑与防御设施监督范围

用户随后要求建筑细化并参考真实防御设备，主线程将这部分一并交给本 agent 独立复核。

当前确认范围为全部17类建筑，8类防御设施重点采用真实设备照片借鉴；激光/护盾/干扰建筑按原创架空功能设计，不能标为已实现实物系统。

- 基地功能从轮廓可读：司令部、工厂/兵营、发电/炼矿/维修、机场/船坞/航天中心应有对应的入口、作业区或功能结构，不能全部是同一盒子换颜色。
- 炮塔、近防炮、防空发射阵地、雷达应区分武器、跟踪探头/雷达、动力/机柜与固定底座。具体参考来源须记录；将移动装置改为固定阵地时明确它是游戏组合。
- 可跟踪上装与固定底座分层；炮塔实际转向目标，建筑根节点不随之转动，雷达扫描节点不把整个建筑一起旋转。
- 制作前查到建筑炮塔潜在方向错误：现有渲染根节点对建筑设为0，但通用炮塔公式仍使用随机 `e.angle - e.turret`；建筑炮塔应按世界目标角转换，不叠加车辆车体角。
- 实际从四象限检查目标跟踪；在图集、主战场和生产卡片均可辨识；保留战雾/电力行为及既有防御作用。
- 无明确具体设备来源的通用建筑与原创高能设施不能借真实照片获得“精确真实还原”标签。

已实际查看最后更新的 `sam_usa-side.png`：四杆脚现由横向底托盘连接，底托盘与中心轴承接触，悬空问题关闭。本轮列出的 P1 视觉项全部经修改与再看图闭环。

验收边界：

- 24槽位包含共享家族主体的卫星、截击舰与反轨车变体，不能说24套完全独立舰型。
- 参考影视的结构语言与氛围，不是影视资产复制或影视级渲染质量认证；现有材质和网格仍风格化，表面纹理/复杂接缝可继续优化。
