# 人员关节步态实现与 CPU 验证

2026-10-18。本轮只改新增 `src/personnel-animation.js`、`tests/personnel-animation.test.cjs`，以及 `src/models-operator.js` 的部件绑定属性和工厂出口。战场/检视器加载和实际 GPU 验收由主 agent 接入。

## 目标与原因

原人员身体、腿和装具合并成静态几何；移动时只有实体位置变化，没有独立屈髋/屈膝动作。新实现保留原创单兵装具外形与 PBR 表面分类，为每人添加 13 个骨骼：躯干、左右髋/膝/踝、左右肩/肘/腕。每人两份 SkinnedMesh，身体和武器/支援装具分别合并；不把每段肢体拆成一个绘制调用。

实际游戏数据的全部 8 类人员、6 阵营覆盖：步兵/突击/反坦克/医疗为三人，机枪/迫击炮/狙击为两人，独立行动员一人。反坦克携带发射筒；机枪带供弹箱；迫击炮组分配炮管与底板；狙击手带长枪管/瞄具；医疗组无武器、带绿色医疗识别包。现版本为持械站立/行走姿态，未制作卧姿与架炮部署动画，也未宣称动作捕捉或实装服饰精确还原。静态图片未知装备与其他真实型号冻结范围不受影响。

## 接入

加载 `personnel-animation.js` 必须在 `model-detail.js`、`models-operator.js` 和所有旧人员注册模块之后。它只重注册上述 8 类人员；其他模型不受影响。

```js
// 每个可见对象设置 position / rotation / scale 后：
WarPersonnelAnimation.update(object, entity, game.time);
// 删除实体或清场前（只释放实例骨骼纹理，不动共享几何/材质）：
WarPersonnelAnimation.release(object);
```

`game.time` 必须使用模拟秒数，不传墙上时钟。暂停时该值不变，因此所有关节/相位保持原样。第一次 update 才为 WarModels 缓存克隆创建独立 Skeleton；对象引用放 WeakMap，不放入 userData，也不共享不同实体的骨骼。`release` 用于永久丢弃实例；需要重新创建对象时继续调用 WarModels.create。

## 运动机制

- 相位依实体 x/y 实际位移累计推进；只有移动订单、原地被阻挡或墙钟增加都不能让角色原地迈步。
- 两脚相位差半周；班组成员略错相，避免队形机械同步。支撑脚保存世界坐标，随后用两骨 IK 解髋/膝/踝，踝部反向补偿保持鞋底水平。摆动脚抬起并向下一落点平滑过渡，倒退和侧移使用实际位移方向。
- 原人员速度 48–84u/s、身高约 9.8u，已达到每秒数个人高；固定小步幅会产生过高步频。采用 1.5–4.2Hz 步频与随速度缩短的支撑占比，快跑更多腾空；全部为游戏表现参数，不代表生物力学仿真。
- 停步在 0.22 模拟秒内归位；模拟暂停不会继续归位。跳跃时停止步相推进，腿部收起，不叠加步态躯干起伏；落地重新建立接地点。
- 模拟时间回退、更新间隔大于 0.30s 或单次异常大位移重置步态，避免读档/传送/离屏再现后腿部狂摆。显著瞬间转向和极端速度跳变不属于真实人体动力学约束求解；不会修改模拟轨迹或玩家输入速度。
- 每个蒙皮网格设置原始几何外扩 0.60u 的保守包围盒/包围球，避免 Three 缓存首次姿势后准星粗筛漏掉移动脚部。不逐帧扫描全体顶点重算包围盒。

## 验证

`node --test tests/personnel-animation.test.cjs`：11/11 通过。包括实际 WarData 人员名单与注册集合相等、48 种组合人数/骨骼/网格/PBR/有效几何、真实位移触发与30/60Hz一致、双腿独立与世界锁脚、暂停、停步归位、跳跃/落地、传送/离屏、缓存独立、倒退/侧移、骨骼纹理释放隔离、蒙皮包围盒。

锁脚用例检验实际骨骼世界坐标，并在 9/48/78/84u/s、前进/后退/侧移、三人班两脚条件下，比较实际 SkinnedMesh 鞋底顶点连续支撑帧的世界坐标。允许误差 1e-5 游戏单位。首轮曾因落脚点叠加踝部 rest.x 导致超过腿长而失败；修复落点基准、步幅与微屈膝后通过，未放宽断言。

`node --test tests/operator-model.test.cjs` 原有 7 项继续通过，证明新增绑定属性未破坏原 operator 静态几何与缓存。

独立监督提出的 Skeleton/boneTexture 生命周期和蒙皮包围盒问题均已修复并新增测试。未执行 GPU/浏览器，也未把 CPU 检查当作视觉通过。

## 资源开销与边界

- 每人 13 骨骼、2 网格；最大三人班 6 网格。帝国三人班最高 25,356 三角形，独立行动员 8,452。
- Intel Core i5-12400F，本机 Node CPU 小基准：100 个三人班、300 人、600 网格；预热20帧后采样60帧，动画更新中位 2.08ms、P95 2.83ms、最大 5.76ms。只包含动画更新，不包含渲染、GPU 蒙皮、阴影、模拟或全场实体处理，不能推断整机帧率。
- 几何和材质缓存共享，骨骼实例独立。与原静态班组相比绘制调用增加，需要主 agent 以实际视野实体数和 GPU 检查帧率；未增加外部运行依赖或第三方动作资产。
- 主流程仍需实际游戏检查持枪手的位置、支援装备识别、行走/快跑/侧移/转身、停步与跳跃，检视器、生产缩略图和桌面 EXE 使用同一模型来源。
