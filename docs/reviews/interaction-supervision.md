## 已实际验证的行为

### 载员与操作边界

- 真实 Game 连续 25 次上下车；同一 crew ID 始终只在场上或一个车内，nextId 不增加；HP 87、主武器弹匣 3 / 备弹 11 保持。
- 上车后不再作为场上目标；载具摧毁时车和乘员各计一次死亡，不复活、不重复计分。
- 同一载员的血量、配装和消耗弹药经过完整 Game.save/load 保持。嵌套与场上 ID 重复、无效弹药拒绝加载；旧档缺车辆及树字段可以加载。
- 水面、水下、飞机、轨道四类平台在无合法地面时保留原乘员与驾驶控制；开放基地附近地面后，退出位置满足地形、基地及树木碰撞约束。
- 实际 keyDown 方法对暂停、未锁定鼠标、军械库、换乘菜单、主模态、隐藏文档、按键重复、INPUT/TEXTAREA/SELECT/contentEditable、文档失焦均阻止 F。这里使用最小 DOM 测试环境，不替代浏览器锁定验收。

### 树与环境伤害

- 真实 Three.Raycaster 对真实 InstancedMesh 求交，实例 ID 映射树 ID 正确；毁坏并 sync 后不再命中对应树，倒伏完成后矩阵清零。
- 死树从原 collider 数组原地删除，驾驶端保留的同一引用立即失去该障碍；邻树 ID、生命值不变。
- 普通 shot 到达前树为 90 HP，到达结算后按伤害扣减；后续 impact 视觉不再次扣血。高空或偏离树的命中不伤树，地面核打击真实毁树，高空核打击不伤远离爆心的地表树。
- 操作员短点击消耗一发弹，携带 targetTreeId 的实际弹着伤树；保存后重载保持树桩。仍在飞行的坦克炮弹经过保存加载，随后只结算一次树伤害。
- 坦克/火箭对树自由瞄准时，treeDamage/treeSplash 有效，同时原 damage/baseDamage/splash 为 0，旁边敌坦克生命值保持不变；环境伤害没有把未命中实体改成命中。
- 部分损伤树的 73 HP 经 JSON 存读档保持且仍有碰撞。地图不匹配、未知树 ID、非有限/负数/超上限 HP 先拒绝，原状态不被部分修改。

### 轨道瞄准

- V 切换实际相机 FOV；倍率 4 / 8 / 16 / 32 / 64 对应精确光学关系 `tan(FOV/2) × zoom = tan(70°/2)`，滚轮上下限有效；0、NaN、正负 Infinity 不改变倍率。
- G 在 4000 与 12000 游戏高度可对准真实 Three 目标几何；鼠标横向在正下方仍改变地面瞄点。64× 同一物体屏幕投影宽度是 4× 的 16 倍。
- 独立补测连续 1000 次横纵鼠标位移，跨过俯视方向后四元数仍有限且归一，平台坐标、高度、射程不变。关闭/重置恢复 70° 与默认 4× 状态。
- 暂停、失锁、模态、菜单、军械库、隐藏与失焦状态下滚轮不改变倍率；已有轨道用例另验证 V 的键重复和文本焦点门禁、失焦清空移动/开火、RMB 不覆盖选定倍率。
- 提示沿用真实 engagementDistance/rangeProfile，区分跨域投影距离与轨道空间距离，并显示己方、超距、EMP、装填等限制；非太空人员/车辆不启用瞄准模式，行动员滚轮仍切换武器。
