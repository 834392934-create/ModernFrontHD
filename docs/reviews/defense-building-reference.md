## 当前模型差距与具体修改

| 类型 | 当前源码可见问题 | 建议几何修改 | 验收判据 |
|---|---|---|---|
| ciws | 已有白雷达罩、六炮管和光电头；基础平台较简单，且上装合并静态网格 | 保留最有辨识度上装；增加下部供弹鼓/弯曲暗色输送带、检修门把手、前后设备箱；静态地基与旋转上装拆开 | 近景能分出雷达罩、光电头、六管与供弹鼓；地基固定，上装随目标转 |
| sam | 四个盒状筒，缺少明显背架，容易像四根漂浮柱 | 采用统一角度的 2×2 筒组；筒尾背板、三角承架、俯仰轴、底座回转环；地面加电源柜与支腿脚盘 | 斜视看到承架的负空间；所有筒连在同一托架，不能每根漂浮；不仿称所有国家都部署 Patriot |
| radar | 细杆撑横向薄板，支撑和设备体量过弱 | 改高竖阵面、厚边框、阵列分块；后方厚设备舱，粗 U 形支座与回转环；电源箱、电缆槽/护栏 | 薄阵面与厚背箱有深度；可区分“雷达阵面”与“发射筒”；无发光射击 |
| bunker | 落入通用建筑分支，有普通玻璃窗，像办公房 | 改低矮厚墙与宽屋顶，周边重复网笼/沙袋块；小黑射孔替代蓝玻璃；后门与顶部通风口；射击点固定在射孔 | 俯视低矮宽厚、侧视射孔小；不能变成高楼或普通厂房 |
| turret | 圆底座+盒子+长筒，缺少安装结构 | 装甲炮塔基座、明确炮耳/防盾、顶置光电观察头；挡墙/弹药柜辅助 | 能与近防多管炮一眼区分；炮管从防盾伸出，指向与效果一致 |
| laser | 目前像加粗传统炮管 | 改短粗双轴光电转台，多窗口正面；后部大电源箱、白/黑散热格栅；发射点是主光学窗 | 不带传统长炮管；冷却与电源设备可见。名称仍“概念”，光束可视化是玩法表达 |
| shield | 与 jammer 同为单细杆顶球 | 原创环形/多柱基座、三/四个粗发射支撑，中央悬置节点；受击局部盾效，平时不遮建筑 | 与单塔 jammer 无色也可区分；明确架空，不提供实物对应背书 |
| jammer | 与 shield 完全同构 | 原创低设备舱+三副不同朝向面板/桅杆天线，侧边电源柜；不装长炮管 | 不像护盾环，不像高竖监视雷达；保留架空标记 |

这些是**真实可见外形启发的游戏阵地**。固定底座和建筑组合属游戏原创。五国共用通用阵地时不要擅自标为真实国家专有型号；帝国额外装甲、金边、高塔也需保留架空属性。

## 其余建筑的职责可读性（原创设计建议，未宣称实物核对完成）

| 建筑 | 最小可辨主形体 | 次级细节 |
|---|---|---|
| hq | 两层指挥舱 + 屋顶通信天线 | 入口遮棚、设备机柜、卫星碟、窗带；避免高耸武器炮管 |
| power | 并列发电机舱 + 变压器/绝缘子 | 粗电缆、散热格栅、短排气筒，与精炼厂立罐区别 |
| refinery | 接矿卸料口 + 传送架 + 处理罐 | 进车坡道清晰；采矿车实际到入口附近卸载；出口不堵导航 |
| barracks | 低长营房 + 小训练院 | 多个门、遮棚、物资箱；不与工厂双宽车门混淆 |
| factory | 宽车间 + 高卷帘门 + 屋顶通风器 | 起重梁/行车，重车出口；生产位置与门口匹配 |
| airfield | 航空库 + 停机坪 + 航标 | 圆/矩形着陆标线；塔台，不用空白道路条冒充完整机场 |
| navalyard | 门式吊机 + 双码头 | 水中开放船坞、护舷、系缆柱；新船出口方向无遮挡 |
| spaceport | 发射架/吊臂 + 开放发射台 | 地面设备箱与通道；不同于大圆盘雷达 |
| repairhub | 开放维修棚 + 吊臂/维修架 | 工具箱、检修坑/升降台；维修十字只作小型识别，不能代替模型 |

## 给监督 agent 的检查

- 上述防御重点做前/侧/顶/透视截图；C-RAM 白罩、SAM 斜筒、雷达竖面、bunker 低墙四类在战场距离可辨。
- 三种“光学/电磁/护盾”概念不可继续同一细杆球体换色。激光短光学头、干扰面板群、护盾多柱环形分别成立。
- 地基/附属柜固定，上装只绕自身轴转；射线/弹丸从实际炮口或光学窗发出，不从建筑中心或地基起射。
- 场景灯光不能把混凝土、涂漆金属、光学窗、网笼都变成同一高光塑料；以清晰材质区分代替堆霓虹。
- 仅照片对照启发，不测算或承诺现实作战性能。新图只在研究目录，发布需保留参考链接及原创说明。
