## 四项关键风险与门槛

1. **深度场景**：水面0、海床-180；潜艇位于水下而非水面换色。水下第一人称必须看到海床、水面底侧/顶部边界与有深度的场景，不被原平地或单面水片挡住。
2. **坐标与命中**：实体海拔、模型姿态、第一人称相机、炮口和落点使用同一XYZ映射；模型+X机首、场景Y向上、水平模拟y对应场景Z。射程/命中考虑高度，固定落点不跨高度追踪命中，水下溅射不误伤水面。
3. **目标域与权限**：水下属于独立域，隐蔽敌潜艇须由有效声呐探测；失去声呐后渲染、选择、小地图、自动追击一致失联。原普通武器不偷偷获得反潜能力；新全域平台实际覆盖六域且保留昂贵成本、先进科技/AI太空禁令。保障潜艇仅维修水下友军。
4. **控制与存档**：暂停、失焦、解锁和EMP不残留推进/升降/射击；固定翼有有限转弯、前进惯性、俯仰升降，直升机可悬停。新状态可保存，旧存档缺字段采用默认，非法数值拒绝。飞行是简化游戏运动，不宣称真实气动。

## 官方实现参考

- [Three PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)：透视近裁面必须大于0、远裁面大于近裁面；改变投影参数后更新投影矩阵。水下近景必须检查近裁切与场景尺度。
- [Three Euler](https://threejs.org/docs/pages/Euler.html)：旋转量为弧度，旋转顺序决定结果；应按实际模型机首轴验证yaw/pitch/roll，不凭属性名字推断。
- [Three Object3D](https://threejs.org/docs/pages/Object3D.html)：局部旋转与世界变换不同，炮口/相机挂点需世界矩阵结果。
- [Three Water](https://threejs.org/docs/pages/Water.html)：官方Water是平面反射效果，默认FrontSide；不能以加入Water类就宣称完成水下体积场景。水下显示需单独处理表面底侧、雾色与海床。
