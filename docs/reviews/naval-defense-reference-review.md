# 海军、防御与其他角色：实物图片审查

审查日期：2026-10-16。范围是游戏外观美术，不包含装备内部、制造图纸或作战技术。`photo-referenced` 仅表示采用照片参考，**不表示精确复刻通过**。

## 原版主要问题

`src/models3d.js` 原 `ship(f,kind)` 未使用阵营参数 `f`。六阵营每个同类舰船的几何完全相同：驱护舰一个通用尖首船体、航母一个窄平甲板、潜艇一个拉长球体。因此游戏名称虽不同，无法凭轮廓辨识。

原近防炮和普通炮塔同用一根炮管，缺少 C-RAM 最醒目的圆柱雷达罩、转炮管束、侧面光电头和摇架。原所有警戒雷达都是相似圆盘，与地面现代阵列雷达的外观差别大。

## 已实现、验证和未通过项

实现文件 `src/models-naval.js`。共 14 个现实舰型注册，另加 3 类通用防御设施（五现实阵营复用）。俄罗斯架空航空舰、帝国海军和轨道平台没有继续生成。每个舰模型合并为一份网格，测试单模型 1 draw call；数据以捕获报告为准。

执行 `node --check src/models-naval.js`、`.tmp/references/naval/check.cjs` 和正式 `tools/capture-model-review.cjs`。按同一视角复看模型后已经修复：滑跃面法向朝下而不可见、潜艇表面明显平面分段、Kalvari 舵面位置、加尔各答桅顶形状、C-RAM 缺失光电头。初次画廊捕获传入不存在的 `ciws_usa` 选项失败，改用 `ciws_chn` 后重新捕获；不将首次失败计为成功。

**目前审查结论：已从“阵营共用玩具模型”进入“可辨识舰型的外观近似”，仍未达到用户要求的接近实物标准。** 阻塞真实性通过的主要点是舰桥/舰岛仍过于方块化、缺少足够一致角度的多张实拍比例校准、部分潜艇只验证了露出水面的部分。纯粹运行无报错不算真实性通过。

后续按以下顺序：固定具体批次→每型至少正侧、前斜、上视的可用实拍→模型同视角正交捕获→先校轮廓和大部件相对位置→再补围栏、门盖、舷窗、旧化和贴花。不能用更多随机方块代替这个过程。

### 第二轮轮廓修正

新增并亲自查看 [辽宁舰右舷航空视图（中国军网）](https://eng.chinamil.com.cn/CHINA_209163/TopStories_209189/9476125.html)、[055 咸阳舰上视图（中国国防部）](https://eng.mod.gov.cn/xb/News_213114/Photos/16352318.html)、[尼米兹右舷侧视（DVIDS）](https://www.dvidshub.net/image/7090267/uss-nimitz-shoots-photo-exercise)。本地分别为 `liaoning2.jpg`、`type055b.jpg`、`nimitz-alt.jpg`。另外尝试取得的 `nimitz3.jpg` 实际是机舱人员、`nimitz-opposite.jpg` 是甲板飞机剪影，已剔除，不当作舰体证据。

按新证据修正：

- 舰体从 8 个粗分段改为 65 个纵向站位、12 点横截面的连续平滑船壳；增加舰首前倾和圆滑舭部，不再以巨大三角平板表示船舷。
- 辽宁舰岛移到舰长中心之后约 14% 舰长处，并降低主体高度、分离前舰桥翼台、后排气块与中部桅杆。这个百分比是本项目图像美术估计，不是实舰工程尺寸。
- 尼米兹按右舷侧视将较小舰岛移到舰长中心之后约 24% 舰长处；另加后方独立桅杆，避免沿用辽宁舰大舰岛。
- 055 的中部上层建筑连为连续低层甲板室，补舰桥侧梯、交通门、艇位、救生筏筒和烟囱格栅；航母补甲板边缘开口、舷侧门及舷台。
- 已重新捕获 14 个现实舰型及 3 类设施的 85 张五视图。第二轮仍只算外观改善，未宣称全部达到实物还原验收线。

## 通用、虚构与未知装备处理

- 防空导弹阵地、联合警戒雷达：游戏通用设施。现在分别使用可辨认的倾斜发射箱阵列、矩形阵列雷达外观；没有擅自指定为 Patriot、HQ-9 或某个已服役具体系统。
- 防御炮塔、火力堡垒、基地、矿山、炼厂、电站、修理站、兵营、工厂：游戏设施，没有对应真实型号。应按结构可信和玩法可读性审查，不能为其编造真实装备照片。
- 装甲采矿车：虚构的 RTS 后勤角色。现实矿卡可作车轮、驾驶室、料斗参考，但不冒充现役军用采矿武器。
- 步兵小组：通用游戏角色；个人武器当前未命名具体型号，不能算“所有制式枪械已还原”。后续若命名枪型，需要单独照片审查。
- 陆基反轨平台、无武装卫星：用途抽象。未核验具体外形，不假称某型号的精确复刻。
- 轨道武装、未来激光塔、护盾、架空电磁塔、六代机概念、战锤阵营：保持旧版占位，依用户顺序等已知型号验收后再生成。
- 核弹、钻地弹等能力：当前是效果与图标，不存在可供模型审查的具体外部弹体；如新增外观，要先选择公开型号/来源，游戏数值不能写成真实技术性能。
