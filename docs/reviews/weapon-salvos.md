# 分时齐射：模拟与现有模型出口

2026-10-20；仅游戏机制，不是现实武器性能或弹道模型。

- `rocket` 现有模型出口：美国 6、俄罗斯 12、中国 8、印度 12、韩国 12、帝国 6。按本项目画出的管／箱口计数，不推断真实装备的其它弹药构型。
- `orbital_missile_barge`：8 个前部圆形出口；后方模块是存储／检修舱，不作为被遮挡的发射口。
- 默认分时间隔：地面火箭 0.16 游戏秒、轨道驳船 0.18 游戏秒；覆盖椭圆半轴分别 52×38 和 46×34 世界单位。均为游戏参数。
- 默认一次齐射总基础伤害仍等于原 `damage`，每枚分摊 `damage / count`；每枚按原装甲、目标域和范围衰减分别结算。分散落点可能降低单一目标受到的总伤害。未将单枚伤害复制为整轮伤害。
- 一轮开始只扣一次装填，默认沿用原 `reload`。配置入口 `game.options.weaponSalvos[kind]`：`interval`、`spreadX`、`spreadY`、`totalDamageMultiplier`、`reloadMultiplier`；弹数固定对应现有模型。

`WarWeaponSalvos` 通过 WeakMap 持有待发队列。`emitShot` 发射第 0 枚；`step` 在模拟时间到达时逐枚创建实际 `shot`。每枚固定终点，后续移动目标不牵引落点；散布中心受最小／最大射程约束。地面自由区域射击不再因为没有目标 ID 而变成零伤害。友军、错误目标域及最小射程盲区继续被伤害规则过滤。已经离架的弹药可由原近防机制拦截。

停火、移动命令、源单位死亡、EMP、阵营改变、驾驶控制丢失或松开扳机取消尚未发射的部分，不退还装填；在途弹继续正常到达。暂停不推进任何发射、飞行或冷却。待发队列不序列化：读档保留在途弹及已扣冷却，舍弃未发部分，避免读档续射或重复扣费。旧 650 个效果上限改为只限制外观效果，不再静默删除正在飞行的伤害弹；存档效果数量校验上限提高到 20000。

模型只新增 Object3D 标记，不修改网格、材质、尺寸或导航包络。`userData.firePorts` 是 `{node,position,direction,parent?}` 数组；`position` 为节点父级局部坐标，使用时以 `node` 的世界坐标为准。默认 `muzzle` 与 `muzzle_0` 重合。射击效果带 `salvoIndex / portIndex / salvoCount`。驾驶输入 `aimOrigins` 和 `emitShot` 的 `aim.origins` 接收各口世界 `{x,y,height}`；后续发射优先当前驾驶输入，缺少时用首发相对车体偏移快照。未收到模型数据时沿用已有原点，不臆造实际尺寸或出口间距。

补充帝国旧海军原型：驱逐舰标记位于现有前炮管端；潜艇缺少可辨发射门，前端游戏出口明确标记 `approximate-forward-hull-exit`，不能当作真实发射管证据。

验证：

- `node --test tests/weapon-salvos.test.cjs`：分时弹数、总伤害守恒、独立固定落点、实时出口、取消、暂停、保存读取、自由覆盖伤害、同军／跨域免伤、最小射程、AI 同路径及高效果负载。
- `node tools/check-salvo-ports.cjs`：12 个齐射模型共 104 个出口，逐个反向射线验证原有表面及前方局部无阻挡；另含 2 个帝国海军边界标记。
- `node tools/check-launch-anchors.cjs`：此前 30 个主炮／发射口保持原网格与包络。
- 本轮未运行 GPU；原生输入、出口渲染和压力由主线程统一验证。
