# 3.6 交互实现与验证范围

目标：第一人称 F 上下车、可破坏树林，以及高轨道精确瞄准。沿用现有单机模拟、Three 渲染与离线桌面包，不新增运行时依赖。

## 控制与状态

人员附近 F 登乘己方空载具；驾驶时 F 离舱并继续人员第一人称。人员实体只存在于战场实体列表或载具乘员槽其中之一，身份、生命、兵种、武器和弹药随人保留。E / Esc 返回总指挥；J 保留原先的游戏快速换乘列表。

海陆空天使用同一换乘事务。海面、高空、轨道离舱属于游戏救生转移，按有限采样搜索合法陆地，检查地形、矿山、树林、建筑和单位占地。无合法点则保留原乘员和驾驶状态。

树木使用固定地图种子和独立随机数生成；90 HP 是游戏平衡值。射击沿原有开火、冷却、耗弹和弹道到达流程结算，环境伤害独立于无效单位目标的零伤害标记。倒木持续 1.2 游戏秒，树桩保留；碰撞及射线遮挡立即解除。实例缓冲、共用几何体和材质在重建地图时释放。

V 切换太空光电瞄准，G 对地俯视，滚轮在 4 / 8 / 16 / 32 / 64 倍中选择。视场为 `2 atan(tan(70°/2)/倍率)`，鼠标按倍率降低灵敏度；接近垂直俯视时使用相机局部轴旋转，避免方位极点难以操作。相机仍在武器实体处，不改高度、射程、伤害或目标兼容性。瞄准时允许绘制远处已侦察模型，仍保留战争迷雾和水下探测限制。

高轨瞄准使用 0.08–500 u 的动态近裁剪面，按瞄点、地表和最近实体的保守包围距离计算，改善 12000 u 高度的深度条纹，同时保留近处同轨单位。离开瞄准恢复原设置。F 换乘保留同一画布的鼠标锁定，不要求再点击恢复控制。

## 验证入口

- `npm test`：模拟行为、乘员唯一性、反复切换、存档校验、树木命中、实例释放、输入门控与光电数学。
- `node tests/vehicle-tree-browser.cjs --desktop`：实际 EXE 的 F、耗弹射树、树桩恢复与第一人称返回。
- `node tests/orbit-scope-browser.cjs --desktop`：实际 EXE 的 V / G / 滚轮、4000 / 12000 u 高度、投射开火和状态信息。
- `node tests/package-consistency.cjs`：源文件与发布目录 SHA-256、模型缩略图和验证报告。

证据以对应 JSON 报告为准；本文件描述设计及验收入口，不代替运行结果。轨道高度和射程采用游戏压缩尺度，画质不宣称达到商业游戏水平。

最终证据汇总见 `docs/v3.6-validation.json`；实际 EXE 的车树、轨道瞄准、军械库、换乘、77 类单位驾驶与原有导入模型校验已执行。性能记录为 RTX 3060、3440×1440 全屏下 96 个移动单位、8 秒样本，不能替代持续战斗压力测试。
