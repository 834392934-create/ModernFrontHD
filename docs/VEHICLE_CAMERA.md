# 3.9.0 载具车外视角

选中己方载具按 E 驾驶，或按 J 选择载具后：

| 输入 | 行为 |
| --- | --- |
| C | 第一人称与车外跟随切换；人员不切换 |
| 按住右键 | 临时光学瞄准；松开后恢复所选视角 |
| 左键 | 开火；右键本身不发射 |
| V | 持续光学观察；再按一次收起 |
| 瞄准时滚轮 | 原有光学倍率 |
| F | 登乘 / 离舱返回人员 |
| E / Esc | 返回总指挥 |
| P | 暂停 |

换乘、离舱、死亡和返回指挥会复位为第一人称。C 不更换当前控制单位，不取消 AI 的建造、生产、护卫管理。飞机鼠标左右保持正常，上推下降、下拉爬升。

## 驾驶呈现

车外显示战场中的同一个模型，保留已有炮塔、旋翼、雷达动画；不叠加第一人称枪械或座舱。取景使用已测量的模型包络及窗口宽高，适配坦克、长舰体、飞机和轨道平台。跟随位置由当前实体姿态直接计算，不累积相机插值；重复绘制或暂停不会使镜头自行漂移。飞机车外镜头保留稳定地平线，机体仍按真实游戏姿态转弯和滚转。

建筑、地形、矿体和存活树木可使后方镜头收近。五条偏移射线保护小范围相机体积；水面和装饰效果不作为实体障碍。潜艇镜头限制在海面以下、海床以上。极端俯仰或紧贴障碍时会压缩可见范围，右键光学瞄准仍可精确观察。

视觉射线从相机发出，伤害射线仍从模型枪口发出；无枪口锚点时沿用原驾驶高度的保守发射点。车外看到掩体后的目标不代表枪口能够穿过掩体。视野、声呐、射程与目标域限制保持有效。

## 验证入口

- `node --test tests/vehicle-camera.test.cjs`：相机几何、输入边界、缓存与物理枪口。
- `node tests/vehicle-camera-browser.cjs --desktop`：实际启动器版本的 C/鼠标输入、69 型载具、五域驾驶与射击、上下车、缩放和原生失焦。精确敌模型/掩体方向采用程序布置的几何夹具，发射使用真实左键；另有可信鼠标移动验证。
- `node tests/package-consistency.cjs`：源码、模型、许可资产和当前原生验收记录一致性。

测试使用独立 `MODERN_FRONT_TEST_PROFILE`。本轮没有修改装备模型几何，没有新增神经渲染或宣称照片级装备还原；实时性能不能由 CPU 几何测试或短场景外推。最终结果见 [VALIDATION.md](VALIDATION.md)。
