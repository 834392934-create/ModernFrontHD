# 玩家驾驶与 AI 保护

进入第一人称后，玩家保留当前载具的移动、瞄准和开火控制；己方 AI 接管其余部队的建造、生产与调度。保护是持续优先响应策略，不能保证玩家或基地绝对不受伤，也不会赋予无敌、免费回血或强制传送。

## 进入与换乘

部署界面选择“第一人称 · AI 建造与护卫”，再选择初始载具。总指挥模式中也可选中己方单位按 E。

J 打开换乘列表，按军种筛选或搜索，点击存活己方单位进入；新生产单位自动加入。换乘列表不暂停模拟，驾驶输入清空，AI 继续经营与防守。Esc 关闭列表，驾驶中 E / Esc 返回总指挥。不能驾驶敌军、已摧毁单位或建筑。

3.4 操作：人员空格跳跃，P 暂停；车辆保留空格暂停兼容。默认关闭晃动，M 可开启。飞机鼠标左右正常、上推下降/下拉爬升；暂停或切出后的运动输入需要重新操作，保留正常飞行惯性。驾驶小地图常驻左侧，10 Hz 更新，亮色箭头显示当前驾驶位置与朝向；地图只读，未侦察目标不会显示，水下目标依赖声呐。

跳跃作用于 7 类人员：使用 32 u/s 初速、80 u/s² 重力，峰高 6.4 u、约 0.8 秒落地。长按不会连跳，空中按键不会预约落地自动跳；仍受原地面碰撞限制，不支持翻墙。参数可通过 options.playerJump 的 impulse / gravity 调整，采用游戏单位。

## 调度规则

- 默认每 1 秒评估一次，只对当前已侦测、仍能作战并具备相应攻击能力的敌人作出响应。失去声呐的潜艇、不可见敌人和 EMP 停机单位不计入当前威胁。
- 优先预留 2 名基地守卫，再选 2 名与玩家相同作战层的护卫；低于 35% 耐久时争取第 3 名护卫。数量受现有兵力限制，HUD 如实显示缺口。
- 基地守卫不参加常规总攻；玩家正在遭受威胁时，护卫不会被抽调回基地。最近且具备正确目标域的可用部队响应威胁；同一部队每轮只接受一个响应目标。
- 陆军和维修队需通过静态地图连通检查，另一岛上的坦克不算可用护卫。动态建筑、树木、拥堵仍交给原有寻路处理，路程和受阻会影响抵达时间。
- 舰艇对岸响应使用可航水域中的攻击移动点，自动攻击射程内目标，不会把岸上目标位置当作航行终点。
- 兼容维修单位优先随行。空中、轨道、水下支援按各自层高逐步靠近玩家，实际回血仍受三维范围和维修对象限制。
- 玩家严重受损时提示撤回，并在状态接口提供建议位置；不会抢夺驾驶权。玩家或基地严重受损可触发既有应急维修，照常支付 400 资源、使用 70 秒基础冷却，并遵守能力总开关及现有增益。

## 生产与建设

缺少合适反制兵种时优先生产可用且买得起的反制单位，其次补维修与护卫。优先订单移动到队列前方，已有付费订单保留；其余生产继续按常规 AI 选择。仍遵守生产建筑、科技许可、人口和资金限制。

供电不足优先补电厂，可以在未满的建筑队列前插队；之后按已侦测的基地威胁补相应防御设施，并考虑维修设施。没有威胁时仍进行常规经济、科技和防御建设。

退出驾驶会清除该模式建立的临时护卫/维修指令和状态，并恢复进入前的玩家 AI 时钟。存档保留已经付款的建设与生产队列，但不会保存驾驶控制或临时保护调令。重新进入驾驶后重新分配保护力量。

## 可配置参数与界面接口

`new WarSim.Game({playerProtection:{...}})` 覆盖参数。默认值在 `WarSim.PLAYER_PROTECTION_DEFAULTS` 集中定义；输入会限制为有效范围。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| tickSeconds | 1 | 策略评估间隔，秒 |
| baseRadius / playerRadius | 650 | 威胁提前响应距离，游戏单位；远程武器按其射程加 100 扩展 |
| guardCount / escortCount | 2 / 2 | 基地守卫及同域护卫目标数量 |
| supportCount | 1 | 随行维修数量 |
| respondersPerThreat / maxThreats | 2 / 4 | 每个威胁最多响应数、每类单轮处理威胁数 |
| criticalRatio | 0.35 | 危急耐久比例 |
| powerReserve | 20 | 建设优先补电的供电余量阈值 |
| holdRadius / refreshDistance | 140 / 80 | 护卫集结半径、重新下达移动目的地的距离阈值 |

`game.protectionStatus` 在驾驶期间提供 `summary` 中文文本，以及 `protectedId`、`playerThreats`、`baseThreats`、`guardIds`、`escortIds`、`supportIds`、`critical`、`fallback`、`updatedAt`。`fallback` 是建议坐标与设施 ID，找不到当前已知安全点时为 `null`。退出驾驶为 `null`。状态只反映本轮已知战况。

## 验证

运行 `node --test tests/player-protection.test.cjs`。测试覆盖目标域分配、基地留守、玩家控制权、维修与真实伤害、资金和科技限制、缺电插队、侦测与 EMP、评估频率、退出与存档、能力资金/冷却/禁用、海底和轨道实际回血、群岛连通及舰艇实际对岸打击。完整回归使用 `npm test`。
