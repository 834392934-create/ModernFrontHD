# 现代战线 HD — 自主设计与执行记录

日期：2026-10-16。用户要求：参考 D:\红警\2024，D 盘独立交付，高清遭遇战、公开真实装备、全球前五阵营、AI、特殊能力、可选增益，全程自主。

## 决策
保留原整合版全部文件。独立目录，无需联网的 Canvas 2D + DOM HUD 游戏；不依赖原游戏素材和商业引擎。自制可缩放的俯视装备轮廓、阴影、地形纹理与特效；不宣称商业级重制或照片级武器模型。Canvas 是为了本地双击、零运行依赖的明确取舍。

阵营口径为 GFP 2026：美国、俄罗斯、中国、印度、韩国。排名不是现实战果预测。陆战为本版范围；真实型号和公开身份用于题材，所有伤害/距离/造价/冷却均为虚构游戏数值。飞机作为可控空中单位与支援，不实现海军。

核心循环：基地收入 → 建造生产设施 → 训练不同兵种 → 占领中立补给站 → 编队推进 → 摧毁敌方指挥部获胜。1 玩家对 1–4 AI，自由混战或 AI 联盟；三地图各有对称出生点、补给争夺和可通行路径。AI 与玩家同样花钱、排队、遵守人口上限，难度差异明确显示。

模块：data.js 装备和规则；sim.js 地图/A*/经济/生产/战斗/AI/视野/序列化；render.js 摄像机/地图缓存/高清装备/特效/小地图；app.js 菜单/输入/界面/本地保存；index.html/style.css；tests 行为回归与浏览器闭环。

## 实施计划
1. 数据与模拟：先建立寻路、阵营、生产花费、地形和胜负行为测试，再实现。
2. 画面与交互：菜单、战场、选中/框选、右键移动攻击、攻击移动、生产、建造、能力、镜头与小地图。
3. 保存和保护：版本化存档、异常提示、失焦暂停、渲染 DPR 上限、人口和粒子上限。
4. QA：Node 测试；真实浏览器五阵营启动、下单、能力、保存恢复、AI 推进、胜负；桌面和窄屏截图；记录局限。

用户明确授权自主设计，因此不增加逐阶段人工确认。直接完成可验证交付。
