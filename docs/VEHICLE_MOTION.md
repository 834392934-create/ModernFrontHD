# 3.10.0 运动、机构与开火

操作：人员继续 WASD 行走，空格跳跃。轮式、履带及舰船 W / S 前进、刹车和倒车，A / D 转向；鼠标独立观察、瞄准。飞机保留鼠标左右正常、上推下降、下拉爬升。C 切换载具内外视角；右键只瞄准，左键开火。

## 运动规则

`vehicle-motion.js` 按人员、轮式、履带、水面、水下、固定翼、旋翼与太空分类；阵营防空车和三种原创轮式车辆另作显式匹配。加减速、反向制动、转速和倒车速度均为游戏参数，不对应真实型号性能。

移动遥测来自碰撞检查之后实际接受的位移。墙前按住 W 不会让车轮空转；倒车轮向反转；履带转向左右差速。松键逐步刹车，暂停、失焦、退出和 EMP 清理输入及速度。读档不恢复瞬时速度。

RTS 的安全方向仍由寻路和局部避让选择，车辆有限转角后前进；狭窄处允许低速自动对正与短距离倒车。手动轮式车辆不能静止转向。这是可玩性的自动驾驶近似，不是真实车辆动力学求解。固定翼的 RTS 到位状态保留游戏抽象，手动驾驶维持最低空速。

矿车的倒车评分按最终矿口/返厂目标计算，避免为省掉头而倒退行驶整个路线。15 个受测矿点均实际卸下500资源，逐步地形合法；最长累计倒车约5.4秒，最长首次交付约182秒。该测试预算210秒，增加累计倒车少于20秒的回归检查。48辆混编窄口约199秒全部到达，验收预算240秒，保持无重叠和合法地形断言。

## 模型机构

原程序模型保留合批几何，车轮、履带鞋和炮管使用刚性骨骼权重，避免每个轮子增加一次绘制。骨骼和运动状态属于每个实例，顶点、纹理和共享材质不随实例修改。

- 实际 T-90M GLB：16个独立轴心，各自按原外形半径转动；182个履带关节。保持23网格、122516三角形、原索引、UV与许可。原作者的一处闭合重叠鞋保持原几何并共用相邻关节。
- 伯克舰 GLB：保留6网格，绑定原主炮塔、双螺旋桨及双尾舵。其他有现成桨舵的模型沿原部件绑定。
- 航空：既有几何分出襟翼、副翼、升降舵及方向舵；旋翼、雷达使用已有独立节点。喷口使用随推力改变的原创尾焰；反推不错误点亮正向主尾喷。尾焰只在渲染实例中创建，不进入导航包络。
- `orbital_mapper` 没有原喷口，只使用既有太阳翼姿态补偿。真实型号没有证据的矢量喷管不凭空添加。
- `carrier`、`repair_ship`、`torpedo_boat`、`arsenal_ship`、`electronic_warfare_ship`、`abyss_tender`、`asw_patrol_ship` 共42阵营槽位缺少可辨的活动机构，明确记录为仅船体运动。中国潜艇模型尾部是深色端帽，不是假造螺旋桨；直行时舵面居中，转弯时偏转。

所有机构使用模拟时间；暂停期间渲染帧继续绘制，但关节、后坐和发射烟生命周期冻结。

## 开火表现

`weapon-effects.js` 映射15类：步枪、机枪、狙击、霰弹、坦克炮、榴弹炮、迫击炮、机炮、舰炮、火箭、导弹、鱼雷、投弹、光束、脉冲。独立监督实际查看5类官方视频关键帧；仅参考可见规律，不把视频剪辑推断为射速、后坐实长或制造参数。

火炮用短闪光、短退慢回和较长烟尘，枪口锚点随炮管。火箭与导弹用发射烟和弹体尾焰，无炮管式后坐；机枪闪光小且短。舰炮不带陆地扬尘，鱼雷用水下尾迹，投弹不出现炮口火球。第一人称武器前景使用同类短闪光包络。

效果只消费真正的 `shot` 事件，最多保留160个发射烟记录，使用模拟时钟过期；不会新增射击、命中、弹药或伤害。飞行中的弹迹继续使用冻结世界坐标并作相机裁剪，不能因转头而重算方向。
