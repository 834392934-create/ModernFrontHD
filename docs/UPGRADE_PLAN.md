# 2026-10-16 画质与玩法改造

目标：同一个离线遭遇战入口，真实三维战场、可辨认的装备外形、可操作的争夺目标。沿用独立模拟和本地 Three.js，不新增运行时下载。

1. 建立照片参考记录。照片只支持可见外形判断，不支持推定保密性能。
2. 重新制作游戏渲染模型：履带、负重轮、低矮车体、分离炮塔、装备可辨认的翼面/发动机布局。原 STEP 作为早期研究源保留；游戏模型独立优化。
3. 新增 Three.js 战场适配器：真实阴影、地面材质、树木、建筑、桥梁、水面、炮塔转向、烟尘；地面拾取与屏幕框选保持一致。共享几何、合并材质、实例化植被。
4. 增加可选据点胜利条件、阵型、集结点、撤退维修、AI 据点决策。保存/加载保留新状态，旧存档兼容。
5. 将装备检视接入同一模型工厂，修复旧贴图拉伸。记录与照片的差异和仍属近似的部分。
6. 模拟测试、浏览器真实输入测试、桌面/窄屏截图、WebGL错误检查、性能样本、离线启动验证，随后更新发布包。

验收：主战场确实使用 WebGL 三维几何；选择/右键/框选/建设无坐标偏移；三种阵型产生不同队列；新兵沿生产建筑集结点移动；据点计分能结束对局；现有科技限制、存档、六阵营保留。性能按实测报告，不把无头软件渲染数字当成 RTX 3060 帧率。
