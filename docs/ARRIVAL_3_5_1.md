# 3.5.1 到位与动作修复

本轮覆盖77种作战单位、6阵营；重点是目的地拥挤、卡住和人员滑步，未更换游戏引擎或宣称达到商业射击游戏画质。

## 原因与处理

战斗命中半径曾同时用于移动避让，明显小于模型。例如中国驱逐舰模型长约145.8游戏单位，旧命中直径仅52；部分无人机翼展也超出旧间距。各次移动命令又只预留本批目标，先到部队与后来部队会争用同一位置。

- 独立导航包围表来自实际加载的462个模型，包括三个GLB资产的四个替换键。命中半径保持原值；人员动态姿态另留余量。修改模型后运行 `node tools/bake-navigation-footprints.cjs` 重烘。
- 同高度实体避让，跨批次预留已停位置、有效订单和队列最终目标。编队保留进入内侧停位的通道，生产出口按完整模型检查。
- 旋转模型盒与地形格做分离轴检查；不以外接大圆误封狭窄通道。局部绕行保持方向，受限可视图与FIFO预算处理已停障碍，转不过墙角时安全倒车退出。
- 第一人称移动与原地转向检查完整船体/车体边界；已非法朝向的旧状态可原地纠正为合法朝向。飞机鼠标左右正常，上推下降、下拉爬升。
- 找不到空间时明确拒绝，保留原指令；单次群体命令最多16384次目的地地形检查，避免无水域时长时间同步扫描。

## 人员

8类人员、48种阵营变体统一关节模型，每人13骨骼、2个蒙皮网格。实际位移驱动步相，支撑脚世界位置锁定，包含膝肘弯曲、停步收姿和跳跃。暂停使用冻结的模拟时间。死亡、换模型和清场释放每实例骨骼资源。战场、检视器、48张更新的生产缩略图使用同一模型来源。

## 验证入口

- `npm test`：模拟、订单、导航、驾驶、存档、脚底真实蒙皮顶点及骨架独立性。
- `node tests/arrival-animation-browser.cjs --desktop`：实际EXE、462模型包围、五域分批到位、8类骨骼GPU显示、岸角六艘混编舰艇。
- `node tests/fps-upgrade-browser.cjs --desktop`：真实锁定鼠标左右与俯仰、小地图和输入稳定。
- `node tests/crowd-desktop.cjs`：注明GPU/分辨率的96单位移动采样。
- `node tests/package-consistency.cjs`：源码与本机EXE资源SHA-256一致。

全部结果以对应 `docs/*report.json` 的本轮时间与通过字段为准。旧55单位间距的密集出生回归保留，用180模拟秒检查解缠、窄口排队及最终停稳；这不代表每条狭窄路线都应立即通过。实体尺寸、有限通道容量和路线长度仍决定排队时间。程序化人员为原创关节动作，未使用动作捕捉；模型几何测试不等于实物外形验收。
