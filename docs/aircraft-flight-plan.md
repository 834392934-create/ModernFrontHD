# 航空流程与全歼规则（3.11.0）

用户要求：飞机按起飞到作战的过程运动，空中不绕建筑；胜利须消灭全部敌方设施及单位。

实现边界：本地确定性游戏模拟，沿用现有机型和伤害/射程。FAA《Airplane Flying Handbook》的滑跑、爬升、协调转弯和进近阶段作为动作参考，速度、跑道长度、航时是游戏尺度，不冒称真实机型性能。
来源：https://www.faa.gov/regulations_policies/handbooks_manuals/aviation/airplane_handbook

固定翼由机场准备、滑跑、爬升、巡航/攻击通场、盘旋、返航进近、着陆维修组成；直升机垂直起飞并保留悬停。机场每条跑道一次放行一架。手动驾驶空中沿用现有鼠标控制与失焦停止；起降交给飞控，R 返航，新的作战指令可取消返航。机场失去时寻找存活机场，找不到则保持空中待命。所有空中单位跳过地面建筑路径搜索，以前视高度净空飞越。

跑道长 360 u、宽 160 u，规划在机场附近合法陆地，避开设施和矿山，清理跑道植被。停机位释放起降占用。跑道受车辆占用时等待；维修受缺电影响减速，不能把已经造好的飞机永久锁在低电量机场。地面 S 停止对应固定翼当前区域盘旋；R 自动返航在失焦/暂停后仍需锁定画面并按 W 恢复。重伤阈值为 25%，空中驻留 180 秒自动返航；仅为可调整的游戏行为参数。

现有飞机外形未在本轮替换；参考的是公开飞行阶段，不是完整飞行模拟器。本轮没有真实燃油/气象/失速计算、航母弹射着舰或新的可收放起落架模型。手动低空接近障碍保留飞行辅助抬高净空；初始严重穿插或极近距离俯冲不等同于真实碰撞动力学。已结束旧存档不复活旧版已清除的军队。

全歼规则适用于新局和未结束旧存档；据点继续提供经济收益但不再触发积分胜利。失去总部的残军继续存在、生产和作战；待建队列不是存活实体，最终单位消灭后不允许队列复活。双方同时全灭按玩家失败处理。

验收：起飞阶段顺序、滑跑加速、爬升、连续转弯与到位盘旋、攻击朝向、返航落地、机场失去、低空建筑直越、暂停/手动接管/存档、残余海空天单位与设施阻止提前胜利、多敌人与最终清除。发布包进行真实独立版操作、阶段截图、源码和版本一致性检查。
