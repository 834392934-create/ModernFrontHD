# 现代战线 HD · 3.2

可离线运行的三维即时战略遭遇战。项目位于 `D:\现代战线HD`；原参考目录 `D:\红警\2024` 未修改。

## 启动

双击 **启动独立版.cmd**，或 **启动游戏.cmd**。发布程序是 `release/ModernFrontHD/ModernFrontHD.exe`，需保留整个同名目录。默认全屏，无浏览器地址栏，无需另外安装Node.js或浏览器。F11切换全屏，Tab隐藏/恢复作战界面。

独立窗口使用Electron + Three.js WebGL；不是Unreal/DirectX引擎重写。资源全部本地加载，不要求账号、服务器或联网AI。浏览器兼容入口保留为 `play.ps1` 或 `index.html`。

`release/ModernFrontHD-portable.zip` 是浏览器兼容包，不含独立版运行时；本机优先使用上面的EXE目录。

## 3.2 水下作战与三维驾驶

总计 **68类单位：陆军18、海军17、空军16、太空16，另有采矿车**；六阵营共408单位外观槽位，含建筑共510图鉴项。新增4种原创角色，公开资料仅用于外形参考；下列价格、伤害、射程、深度和速度全部为游戏值。

|新单位|价格|玩法|
|---|---:|---|
|深海猎潜艇|2,600|声呐500范围，鱼雷攻击水面舰艇和水下单位|
|深海保障潜艇|2,100|无武装，35/秒维修水下友军，声呐360范围|
|寰宇全域突击机（架空）|12,000|空中机动平台，220伤害/1.5秒装填，射程600，六域打击|
|寰宇全域无畏舰（架空）|20,000|轨道重平台，6,000耐久、400伤害/2.5秒装填，射程850，六域打击|

六域指地面、水面、水下、空中、轨道、基地目标；全域单位有反潜传感器，可打击这些目标，但仍分别属于空军/太空军，不会变形成潜艇。两种全域平台受“尖端科技仅玩家”控制，无畏舰同时受“禁止AI太空武器”限制。

- **水下**：旧潜艇也进入水下层；驱逐舰、反潜护卫舰配声呐和反潜鱼雷。敌潜艇须被己方有效声呐探测，光学视野不替代声呐；全图视野增益是明确的例外。目标丢失后停止追踪。普通地面武器和旧轨道武器不自动获得反潜能力。
- **潜艇第一人称**：E进入，WASD平移、鼠标观察、Shift上浮、Ctrl下潜，左键发射。深度22–140游戏单位；有实际下沉的海床、水面底侧、悬浮颗粒、压力窗与声呐屏。声呐屏仅显示已探测敌潜艇。
- **固定翼飞机**：W/S增减油门，鼠标控制机头方向，A/D转弯并滚转，Shift/Ctrl辅助爬升/下降。有前进惯性、有限转弯速率和25–650高度范围；不能原地横移或倒飞。直升机可以悬停、平移升降；轨道平台高度120–900。高度、速度、俯仰、滚转在HUD显示。
- **暂停/失焦/解锁/EMP**会清空驾驶输入并暂停推进；恢复后需重新操作。E/Esc返回总指挥，AI代管其余队伍。射程、命中、维修与局部支援计算包括高度差，固定落点不追踪逃出高度层的目标。防御圈显示名义水平投影，存在高度差时可用水平射程更短。

飞机使用简化三维游戏运动，不含真实升力、失速、气动或完整碰撞损毁模拟；低空建筑和树干使用保守高度避碰。单位外观和座舱仍是风格化模型，没有达到商业AAA画质。

|军种|新增单位|实际作用（游戏参数）|
|---|---|---|

## 3.0 第一人称接管与增援（沿用）

选中任意存活的己方单位，点击“第一人称驾驶”或按 **E**。相机进入该实体的真实位置；其他部队的建造、生产和战术调度交给己方 AI。按 **E / Esc** 返回总指挥。步兵显示持枪双手，医护显示医疗装具，装甲/舰艇/航空/轨道单位分别显示炮镜、舰桥或座舱仪表。自身外部模型隐藏，其他单位仍在同一个战场作战。

- **WASD** 移动，鼠标观察，左键开火，右键瞄准；**空格** 暂停，**M** 关闭/开启晃动，**F11** 全屏。失焦和鼠标解锁立即清空移动及开火输入。
- 手动射击沿准星与炮口双重射线检查遮挡（未标炮口的旧模型采用保守发射点），按固定弹着点及目标命中区域近似判断，移出区域不再追踪扣血；命中标记只在实际伤害结算后出现；冷却、射程、目标域、护盾、弹道延时和增益沿用 RTS 规则。无武装单位可驾驶，医疗/维修/电子支援继续自动工作。
- 新增 12 种原创职责单位，该版为 **56 类单位：陆军16、海军13、空军13、太空13，另加采矿车**。这12种在六阵营共享职责造型并使用阵营涂装，共72个新外观槽位，不冒称72种真实装备。

|军种|新增单位|实际玩法|
|---|---|---|
|陆军|反坦克导弹车、重型攻城榴弹炮、战地医护|反装甲、远程攻坚与最小射程、仅治疗步兵|
|海军|高速鱼雷艇、武库舰、护航轻型护卫舰|近程对舰鱼雷、远距对岸/舰火力、机炮与独立火箭拦截|
|空军|救援直升机、对海攻击机、电子战飞机|救治地面步兵、专职反舰、延长敌方指定军种装填时间|
|太空|轨道护航舰、轨道中继站、轨道干扰舰|空天近卫、缩短友军空天装填、干扰敌方轨道装填|

同类电子场取最强效果，不重复累加；友方加成与敌方干扰可以同时作用。关闭 AI 太空武器也禁用攻击性轨道干扰舰，保留无武装维修/侦察/中继。

3.0初版第一人称空天单位曾保持固定高度；3.2已加入上述三维驾驶。步兵仍代表班组，不含完整人物骨骼动画、弹匣系统或室内关卡。材质、近景模型、阴影和反馈已针对近距离改善，但**没有达到《使命召唤》的资产与画质水平**。未集成 DLSS、光追或商业游戏组件。

## 当前玩法

- 美国、俄罗斯、中国、印度、韩国、战锤人类帝国同人阵营；1玩家对1–4 AI，支持混战/敌方联盟。
- 简单、标准、困难、极难四档AI；高难度包含经济补助，不能等同于公平经济下更聪明。
- 三张地图、连通海域、陆路桥梁、矿山、补给据点；基地歼灭与据点积分胜利规则。
- 68类单位：陆军18、海军17、空军16、太空16，另有采矿车、17类基地/防御设施、7类支援能力、8项玩家增益；本地保存和JSON导入导出。
- 每矿山初始24,000资源；采矿车容量500、装载65/秒，自动往返装车区和炼厂。采空后另寻矿源，炼厂损失时保留货物等待。矿体阻挡车辆，装车区可达。
- 陆海空生产线分别推进；集结点、队形、排队路径、撤退维修、近防火箭拦截、雷达防御增益。
- 尖端科技仅玩家可用与禁止AI太空武器独立设置；可在对局内更改，禁止后退还AI相关排队订单。轨道武器可攻击海陆空、轨道目标和基地。

太空重平台保留海陆空天及基地攻击；新截击舰只打空中/太空，速度145、伤害95/0.95秒；重平台速度62、伤害200/3.2秒（均为游戏数值）。AI太空开关控制全部武装太空单位和攻击性干扰舰；侦察星、测绘星、维修站、中继及无武装护盾舰仍可用。

新增27类按公开装备形态与原创职责设计，包含侦察、反装甲、维修、对空、对舰、岸轰与轨道攻城等；不是换名复制既有进口模型。生产界面可切四类并搜索名称/职责，尖端科技未开启时仍显示锁定卡片。AI按相同目标域战斗，维修跟随对应军种；舰队沿同一连通水域推进。

防御提示：悬停或选中显示攻击、拦截、维修、雷达联动等范围；V循环选中/己方防线/关闭。建造时显示投影范围与建成后电力；EMP/缺电用虚线及文字提示。雷达增程只影响攻击，近防拦截半径维持330。全部距离为游戏单位。

## 外观与真实资料

主战场使用实时三维模型；装备检视提供透视/正/侧/后/俯五视图。五国坦克、步战车、自行炮、火箭炮、防空车、战机、直升机和舰艇分别按实物照片重建。三名agent的差异审查见 [审查目录](docs/reviews/)。

大部分装备为原创程序网格；俄罗斯T-90M、美国伯克级与美韩AH-64已接入有CC-BY署名许可的离线美术资产。T-90M保留独立炮塔，AH-64保留主/尾旋翼动画。AH-64按Longbow家族参考外观展示，不认证某个AH-64E生产批次。具体作者、来源、改动和许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。

**尚未完成所有型号“接近实物”的视觉终验。** 功能测试、部件数和三角面数不能代表真实性。照片仅支持可见外观；原创航天单元不冒称现实已部署装备。25个地面槽位通过一级轮廓初审，详细剩余项见 [验收顺序](docs/reviews/ACCEPTANCE_POLICY.md) 和 [49个实物槽位清单](docs/reviews/KNOWN_EQUIPMENT.md)。

2026-10-16 用户新增授权太空4型与全部17类建筑细化：6阵营24个太空槽位，区分无武装侦察、空天截击、全域重型打击和地面反轨；帝国太空舰采用厚装甲、高塔和侧舷炮舱。建筑借鉴 C-RAM、Patriot、TPY-4、HESCO 和光电设备照片，游戏组合不冒称精确实物。六代机与其余未知车辆舰机继续保持旧版占位。证据与冻结范围见 [图片来源](docs/VISUAL_REFERENCES.md)。

公开资料与游戏数值分开；未知射程、防护和毁伤不填假精确值。概念能力为游戏强化，不是现实仿真。没有集成DLSS或光追，详见 [画质说明](docs/GRAPHICS.md)。
