# 现代战线 HD

独立、可离线运行的俯视即时战略遭遇战原型。代码与素材在本目录，原游戏 `D:\红警\2024` 保持不变。

## 启动

双击 **启动游戏.cmd**。本机已有 Node.js：启动器会在后台启动或复用仅监听 `127.0.0.1` 的服务器，自动打开浏览器。端口从 8765 到 8775 检查，避免冲突。

没有 Node.js 时，启动器回退到 `index.html`。也可以直接双击该文件：游戏与 3D 检视均能离线运行；部分浏览器限制本地文件的 GPU 后处理，此时自动使用标准画面。

已在 Chromium 验证，完整操作面向桌面鼠标键盘。无登录、无付费运行依赖、无网络资源或在线 AI 服务。

## 当前内容

- 美国、俄罗斯、中国、印度、韩国，以及超规格的战锤·人类帝国同人阵营。
- 1 玩家对 1–4 AI，AI 阵营可单独选择；自由混战或敌方联盟，三档难度。
- 三张地图：双河前线、赤沙盆地、灰港工业区；均有连通海域、基地与补给站。
- 15 类海陆空天单位；17 类基地及防御设施；7 类支援能力。
- 核打击、钻地弹、六代概念机、轨道武装、定向能与护盾；尖端科技默认仅玩家可用，可在开局和对局内调整。
- 8 项玩家增益、单位生产、建筑放置、电力、占点、迷雾、编组、暂停、倍速、胜负结算。
- 本地保存 / 读取，以及 JSON 存档导出 / 导入。
- 公开装备资料库；五国独立坦克外观研究与 3D 装备检视；参数化 STEP 源文件。

## 真实数据与概念边界

这是可玩的原型，**不是《红警》高清重制、不是《坦克世界》级商业资产，也不是现实作战仿真。**

真实装备型号用于题材，资料库将已核实的公开字段、未知项和游戏数值分开。可靠机动数据用于相对速度映射；射程、毁伤、防护、产能和轨道层有显著抽象。概念性能是同类基线上的玩法强化，不能当作真实参数。

坦克模型已按各车型公开外观区分，但没有摄影测量或逐面尺寸核验；部分其他兵种仍使用通用轮廓。六代概念机不宣称是真实最终构型。太空武装、护盾与部分舰艇是明确标记的架空装备。

本机 RTX 3060；本版没有集成 DLSS 5、光线重建或光线追踪。采用 CAD 预渲染与 WebGL2 后处理，详见 [光影说明](docs/GRAPHICS.md)。

## 开发与验证

```powershell
npm test
node server.cjs
# 另一个终端；需要安装 Playwright，或指定现有模块绝对路径：
$env:PLAYWRIGHT_MODULE = '你的/playwright/模块路径'
node tests/browser.cjs
node tests/acceptance.cjs
node tests/gallery.cjs
```

开发使用本机已有的 Playwright，运行游戏不需要它。报告见 `docs/acceptance-report.json`、`docs/gallery-report.json` 和 `screenshots/`。

CAD 源码在 `models/`；STEP 可由 Fusion / FreeCAD 打开。需要重建时安装 `models/requirements.txt`；`models/bake_sprites.py` 从同一几何生成图集与 3D 检视网格。建模依赖只用于开发，不是游戏启动条件。

## Git 推送

已建立本地 Git 仓库，分支 `codex/modern-front-hd`。尚未配置远端。先在自己的账户创建一个空仓库，然后执行：

```powershell
cd 'D:\现代战线HD'
git remote add origin '你的远端仓库URL'
git push -u origin codex/modern-front-hd
```

仓库忽略 `.venv`、缓存、日志和本地存档。不要把账号令牌写进代码或远端 URL。
